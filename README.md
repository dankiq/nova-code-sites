# NOVA CODE

Портфолио и сайт услуг Артёма. Восстановлены из опубликованных файлов и резервной копии REG.RU.

- `nova-code-portfolio/` — портфолио, кейсы и демо.
- `nova-code-web/` — услуги и мини-бриф.

Публикация: SourceCraft Sites, репозиторий `nova-code-sites`. Серверная часть PHP не публикуется. Форма готовит сообщение для ручной отправки в Telegram.

## Открыть сайты

- https://novacode-artem.sourcecraft.site/nova-code-sites/nova-code-portfolio/
- https://novacode-artem.sourcecraft.site/nova-code-sites/nova-code-web/

Публикация включена из ветки `publish` в SourceCraft. Ветка `main` зеркалируется из GitHub; обновления из неё нужно переносить в `publish`. Корневой путь `/nova-code-sites/` встроен в ссылки и ресурсы: при переносе на другой адрес требуется изменить этот префикс.

Восстановлена готовая версия сайтов: HTML, CSS, JavaScript, изображения и доступные демо. Исходные React/Next.js-компоненты до сборки в резервных копиях не найдены. Старый PHP-обработчик и конфиденциальные файлы сервера исключены. Утилиты и проекты из каталога не восстанавливались целиком: сохранено то, что было опубликовано на самом сайте.

Telegram `twincode_dev`, VK и телефон сохранены из прежних сайтов как существующие каналы связи; новое название не меняет адрес мессенджера. Для формы требуется отдельная отправка подготовленного сообщения в Telegram.

21.10.2026 проверены открытие главных страниц на SourceCraft, каталог и фильтр работ, браузерный сценарий бота и страница услуги. В браузере сайт открывается; отдельная проверка через всех российских операторов не проводилась. Некоторые демо, использующие worker или встраивание, могут зависеть от ограничений статического хостинга.


## Карты, контент и аналитика

Добавлена страница `/nova-code-web/services/business-maps/` и её копия в `/nova-code-portfolio/business-maps/`. Общие стили — `geo-services.css`, локальный конструктор сообщения — `geo-brief.js`. На сайте услуг появился подробный блок; в портфолио — ссылка в меню и вкладка услуг. Обратная связь использует прежние 18 записей как краткие пересказы. Оценка 5/5 отдельно атрибутирована воспоминаниям Артёма; новые имена, даты, цитаты и результаты не добавлялись.
