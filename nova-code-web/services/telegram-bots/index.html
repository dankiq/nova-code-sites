Вопросы

Оцениваем по сценарию, а не количеству кнопок.

Можно подключить оплату?

Да, если выбранный провайдер предоставляет подходящий API и условия работы соответствуют его правилам. После оплаты бот может автоматически выдавать доступ или материал.

Нужен отдельный сервер?

Для постоянно работающего бота обычно нужен хостинг. Подберём конфигурацию, развернём проект и передадим доступы.

Кто сможет менять тексты и настройки?

Для часто меняемых данных делаю простую админку или служебные команды с ограничением по пользователям.
