Вопросы

Что важно знать до разработки.

Сайт действительно будет многостраничным?

Да. Основные разделы получают собственные адреса и метаданные, а навигация связывает их между собой. Это полезно для посетителей, рекламы и органического поиска.

Можно потом добавлять страницы?

Да. Структуру собираю так, чтобы новые услуги, кейсы и статьи можно было добавлять без переделки всего проекта.

Вы подключаете домен и аналитику?

Да. Публикация, HTTPS, Яндекс Метрика и базовые цели входят в запуск.
