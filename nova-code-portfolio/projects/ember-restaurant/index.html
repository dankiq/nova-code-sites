Сайт ресторана должен передавать температуру места до того, как гость увидит меню.

Открыть демо-сайт
Задача

Кинематографичный сайт камерного ресторана с историей бренда, меню по категориям и интерактивной бронью стола.

Что требовалось

  • Передать атмосферу открытого огня и камерного ужина.
  • Сделать сезонное меню удобным для просмотра без PDF-файлов.
  • Собрать компактный сценарий выбора даты, времени и числа гостей.

Что реализовано

  • Иммерсивная обложка ресторана
  • Переключение категорий меню
  • Состав и стоимость каждого блюда
  • Интерактивный выбор количества гостей
  • Демонстрационный сценарий бронирования
Результат

Готовая концепция для ресторана, бара или загородного проекта с сильной визуальной идентичностью.
