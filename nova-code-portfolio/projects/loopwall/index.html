LoopWall

Живой рабочий стол без прожорливого браузерного движка.

GitHub / скачать
Задача

Лёгкие видеообои для Windows: точный A/B loop прямо из MP4, отдельные профили мониторов и автоматическая пауза во время игры.

Что требовалось

  • Воспроизводить видео плавно и с аппаратным декодированием.
  • Дать каждому монитору собственный ролик, отрезок и режим кадра.
  • Освобождать ресурсы во время игры и надёжно восстанавливаться после неё.

Что реализовано

  • Монтажный таймлайн с A/B loop
  • Профили для нескольких мониторов
  • mpv / D3D11VA и fallback-декодер
  • Пауза и выгрузка RAM / VRAM
  • Автозапуск, трей и диагностика
Результат

Бесплатная Windows-сборка, инструкция по установке и открытый исходный код опубликованы на GitHub.
