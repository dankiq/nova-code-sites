AssetGuard

Перед публикацией сайт должен пройти быструю техническую приёмку, а проблемы должны быть видны в одном месте.

Открыть отчёт Скачать аудитор
Задача

CLI-аудитор ресурсов сайта. Находит тяжёлые файлы, одинаковые ресурсы и битые локальные ссылки в HTML и CSS, оценивает здоровье проекта и собирает HTML- и JSON-отчёты.

Что требовалось

  • Проверять проект рекурсивно и пропускать служебные каталоги.
  • Находить ссылки из src, href, srcset, poster и CSS url().
  • Показывать потенциальную экономию от удаления дубликатов.

Что реализовано

  • Контроль веса ресурсов
  • Битые локальные ссылки
  • Дубликаты по SHA-256
  • Настраиваемый порог размера
  • HTML и JSON отчёты
Результат

Автономный Node.js-инструмент без npm-зависимостей, пригодный для локальной проверки и CI перед деплоем.
