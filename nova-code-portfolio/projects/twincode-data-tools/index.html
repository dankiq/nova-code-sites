Скачать beta
Задача

Три локальные Windows-утилиты в одном EXE: сравнение прайсов, очистка клиентских таблиц и обезличивание данных.

Что требовалось

  • Закрыть три частые задачи с таблицами без аккаунтов и облака.
  • Поддержать разные форматы и кодировки, включая CP1251.
  • Не изменять исходный файл и оставлять проверяемый результат.

Что реализовано

  • PriceMatch: сверка прайсов
  • TableMedic: очистка и дедупликация
  • SafeSheet: маскирование данных
  • Excel-отчёты и журнал изменений
  • GUI, CLI и автономная EXE-сборка
Результат

Beta-сборка для Windows работает без установки Python. В комплекте есть примеры файлов и краткая инструкция.
