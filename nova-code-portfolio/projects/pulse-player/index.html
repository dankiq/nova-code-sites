PULSE Player

Поиск, локальные файлы, очередь и избранное находятся в одном окне.

Запросить сборку
Задача

Desktop-плеер с единым поиском, локальной библиотекой, очередью, избранным и официальными интеграциями музыкальных платформ.

Что требовалось

  • Объединить поиск, локальные треки и внешние источники.
  • Сохранить очередь, историю, избранное и настройки локально.
  • Работать через официальные API без обхода DRM.

Что реализовано

  • Поддержка популярных аудиоформатов
  • Поиск и preview через Apple / iTunes
  • Очередь, shuffle, repeat и история
  • Media keys и системная Media Session
  • Анимированная обложка и визуализатор
Результат

Ранняя версия уже воспроизводит локальные треки, хранит библиотеку и работает с внешними источниками. Интерфейс и часть функций ещё дорабатываются.
