TabTamer

Десятки вкладок остаются рабочим пространством, а не превращаются в очередь из одинаковых иконок.

Посмотреть интерфейс Скачать расширение
Задача

Расширение для порядка во вкладках Chrome. Анализирует текущее окно, группирует страницы по доменам, закрывает точные дубликаты и сохраняет рабочую сессию для восстановления.

Что требовалось

  • Показать состояние окна и количество повторов с первого взгляда.
  • Использовать нативные группы Chrome вместо собственной оболочки над браузером.
  • Сохранять и восстанавливать сессии без внешнего аккаунта.

Что реализовано

  • Группировка по домену
  • Удаление дубликатов URL
  • Сохранение сессии
  • Восстановление вкладок
  • Горячая клавиша
Результат

Полноценное расширение Chrome с Manifest V3 и отдельным интерактивным демо интерфейса.
