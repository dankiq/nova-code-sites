Задача

Интерактивный конструктор брифа для первого разговора с клиентом. Собирает цели, сроки, бюджет и требования, оценивает готовность задачи и выгружает аккуратное резюме в Markdown.

Что требовалось

  • Собрать ключевые вводные без длинных анкет и лишней терминологии.
  • Показывать готовность брифа и краткое резюме прямо во время заполнения.
  • Хранить данные локально и отдавать документ, который удобно переслать команде.

Что реализовано

  • Автосохранение без регистрации
  • Индикатор готовности задачи
  • Динамическое резюме
  • Экспорт в Markdown
  • Адаптивный интерфейс
Результат

Рабочий браузерный инструмент, который сокращает подготовку к оценке проекта до нескольких минут и не отправляет данные в облако.
