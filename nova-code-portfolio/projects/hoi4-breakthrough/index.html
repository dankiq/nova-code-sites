HOI4 Breakthrough

Калькулятор быстро показывает шанс прорыва и параметры, которые мешают атаке.

Задача

Компактный калькулятор, который оценивает шанс прорыва фронта в Hearts of Iron IV и показывает, какие параметры мешают атаке.

Что требовалось

  • Свести боевые модификаторы к понятной экспресс-оценке.
  • Показать риск цветом и подсказать нужное число дивизий.
  • Собрать автономный EXE без требования Python у пользователя.

Что реализовано

  • Шанс прорыва и цветовая оценка
  • Авиация, форты, местность и зима
  • Подсказка для достижения 80%
  • Окно поверх игры и глобальные клавиши
  • История значений и текстовые отчёты
Результат

Готовый переносимый EXE с тестами расчётов, историей значений и режимом поверх игры.
